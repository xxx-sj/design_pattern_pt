# 데코레이터

### 기능은 확장하고싶은데, 상속은 쓰고싶지 않을 때
### 자유롭게 붙였다 뗐다 하고 싶을 때
### 원본 객체 코드를 수정하지 않고 기능을 추가해야 할 때
### 부가기능을 여러 객체에 일관되게 적용하고 싶을 때
- 로깅 추가
- 성능 측정
- 트랜잭션 등등

- 응답 값에 덧붙여서 리턴하게 됨.
- 기본 component (coffee)가 있고
- 이것을 구현한 concrete component가 있는 상황에서
- 여기에 decorator를 붙여서 더 감싸고 싶을 때
- 추가적으로 decorator들은 coffee를 구현하게 되고 
- 생성자를 통해 concrete component를 받는다.
- 그렇게 component에 정의되어있는 메서드에 필요한 내용을 덧 붙이게 된다.
